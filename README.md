# KermenX Release Distribution

Repository publik distribusi rilis dan endpoint pembaruan otomatis (In-App Auto-Updater) untuk aplikasi **KermenX Desktop**.

## Berkas Rilis
- `version.json`: Endpoint manifest versi terkini aplikasi KermenX.
- `KermenX-Update.zip`: Paket rilis aplikasi (.NET WPF runtime & binaries).
